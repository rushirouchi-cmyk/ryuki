# tl;dv 議事録自動格納フロー

アポ (商談・定例 MTG) 終了後、tl;dv に保存された録画の文字起こしから議事録と次回アクションを生成し、Google スプレッドシートとして Google Drive に自動格納する仕組み。

**ステータス**: 稼働中 (2026-07-16 設定)

## 全体フロー

```
tl;dv (録画・文字起こし)
   │  ① search-meetings で直近 26 時間の会議を取得 (毎時実行)
   ▼
重複チェック
   │  ② Drive を `title contains 'tldv-<meetingId>'` で検索し、
   │     既に議事録があればスキップ
   ▼
議事録生成 (Claude)
   │  ③ get-meeting-notes (AI ノート) → 空なら get-meeting-transcript
   │     を入力に、議事録 + 次回アクションを生成
   ▼
Google Drive
      ④ フォルダ「商談議事録（tl;dv自動）」に CSV → Google
         スプレッドシート変換で 1 会議 = 1 ファイル作成
```

## 実行基盤

| 項目 | 値 |
| --- | --- |
| 実行方式 | Claude Code Remote の Routine (cron トリガー) |
| スケジュール | 毎時 23 分 (`23 * * * *`) |
| トリガー名 | `tl;dv商談議事録の自動スプレッドシート格納` |
| 発火先 | 設定元セッションに self-bind (tldv / Google Drive コネクタを保持) |
| 格納先フォルダ | `商談議事録（tl;dv自動）` (Drive フォルダ ID: `10xMGtJWWo2YWrXYmdPN0-B1slvMDgBnb`) |

### 冪等性 (二重処理防止)

ファイル名末尾に `[tldv-<meetingId>]` を必ず含める。実行のたびに
Drive をこのタグで検索し、ヒットした会議はスキップする。検索窓口を
26 時間 (実行間隔 1 時間 + バッファ) にすることで、取りこぼしと
タイムゾーン差異を吸収する。

## 出力フォーマット

- ファイル名: `【商談議事録】YYYY-MM-DD <会議名> [tldv-<meetingId>]` (JST 基準)
- 形式: CSV をアップロードし Google スプレッドシートに自動変換 (2 列: `項目`, `内容`)

| 行 | 内容 |
| --- | --- |
| 会議名 | tl;dv 上の会議タイトル |
| 開催日時 | JST 表記 + 所要時間 |
| 参加者 | 社名・役割が分かれば併記 |
| 録画URL | tl;dv の再生 URL |
| 会議の目的 | 1〜2 文 |
| 概要 | 3〜5 文のサマリ |
| 主なポイント | ■ 見出し + 箇条書き。金額・人数・日付等の数値は必ず保持 |
| 決定事項 | 箇条書き |
| 次回アクション | 【担当者/会社】ごとに区分した箇条書き |
| 次回MTG | 日時・場所 (リンク)・参加者 |

議事録生成プロンプトの詳細は [`prompts/minutes_writer.md`](../prompts/minutes_writer.md) を参照。

## 制約と今後の改善

- **1 会議 = 1 スプレッドシート**: 現行の Google Drive コネクタには既存
  ファイルの更新 (行追記) ツールがないため、マスター一覧シートへの追記は
  できない。Google Sheets API を叩ける MCP を導入すれば、単一マスター
  シートに 1 会議 = 1 行で追記する方式へ移行できる。
- **コネクタの引き継ぎ**: 新規セッション起動型の Routine にはコネクタが
  引き継がれないため、self-bind 方式を採用している。設定元セッションが
  失効した場合は、claude.ai の Routines UI からコネクタ付きで作り直すのが
  確実。
- **議事録データはリポジトリに置かない**: 本リポジトリは public のため、
  顧客名・商談内容を含む生成物は Google Drive のみに保存する。

## 運用

- 一時停止 / 再開 / 削除: claude.ai の Routines UI、または
  `update_trigger` / `delete_trigger` ツールから操作。
- 手動実行: `fire_trigger` で即時発火できる (過去 26 時間分を処理)。
- 格納先を変えたい場合: トリガーのプロンプト内のフォルダ ID を差し替える。
